# Release notes

Each release has a unique tag. The tag uses semantic versioning.
The full page for a release is on GitHub.
These notes are a summary. They are not a git log.

No release in this file is signed.

## 0.9.0

A program cannot move the pointer onto Approve.
The card accepts a click only after the person moves the mouse.
The release replaces `System.Security.Cryptography.Pkcs` with 10.0.13.
That fix is GHSA-846f-f764-76mx.
Gate decisions can go to the Windows Event Log.
Team rules can only lower a level.
https://github.com/BasantPandey/CmdWarden/releases/tag/v0.9.0
